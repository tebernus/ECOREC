# Unified Data Framework Dashboard
National accounts, environmental-economic accounts, health accounts, flow-of-funds statistics and distributional accounts each measure one dimension of economic performance, yet they are compiled separately and rarely closed into a single, balancing system. This paper develops a framework that does close them: a square extended social accounting matrix in which the System of National Accounts, financial flow-of-funds, the System of Environmental-Economic Accounting, the System of Health Accounts and household distributional accounts appear as blocks of one matrix, and in which the whole system is solved as a coupled linear multiplier. The framework yields an extended multiplier matrix whose entries trace how a policy shock propagates through production, income distribution, health financing, credit
creation and emissions, including feedbacks that standard multiplier models treat as exogenous. A fully reconciling numerical benchmark economy is constructed to make the accounting constraints visible, and the same economy is then solved under three nested closures---an open $5\times5$ monetary core, a financially closed $6\times6$ core and a fully coupled $7\times7$ system---which shows that endogenising health, finance and pollution changes both the size and the distribution of policy effects, and that defensive health spending can raise measured output while lowering household income. Because a tool is only useful if it can be run, the framework is implemented as a single, self-contained HTML file that solves the model exactly in the browser; its complete source, together with instructions for deploying it on the web, is reported in the appendices.
